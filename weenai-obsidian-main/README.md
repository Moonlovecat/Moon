# weenai-obsidian

Shared private Obsidian workspace for planning and documentation of the weenai project.

## Suggested Structure
- `00-Inbox`: quick capture
- `01-Project-Home`: project overview, goals, roadmap
- `02-Planning`: milestones, tasks, sprint planning
- `03-Research`: competitor research, references, ideas
- `04-Game-Reviews`: review drafts and review framework
- `05-Design`: IA, wireframes, UX notes, content structure
- `06-Meeting-Notes`: team discussions and decisions
- `07-Assets`: shared text assets and references
- `99-Archive`: old notes
